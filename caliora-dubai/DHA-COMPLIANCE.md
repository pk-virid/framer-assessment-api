# DHA / MOHAP compliance rules for this template

This template is designed so Dubai clinic buyers can market ethically under:

- DHA Standards for Medical Advertisement Content on Social Media (HRS)
- DHA Standards for Code of Ethics and Professional Conduct for Health Professionals (2026)
- Executive Council Resolution No. (49) of 2024 (health promotion authorisation)

**Important:** The template provides compliant *default copy and UI slots*. Each clinic must still obtain their own DHA/MOHAP advertisement licence and Medical Director approval before publishing live marketing.

## Hard rules encoded in copy

1. **No guaranteed outcomes** — never “guaranteed smile”, “100% pain-free”, “permanent forever”, “miracle”, “infallible”.
2. **No superiority claims** — never “best dentist in Dubai”, “#1 clinic”, “better than other clinics”.
3. **No absolute / alarming claims** — avoid exaggerated urgency (“don’t delay or lose your teeth”).
4. **Titles match licence** — use only DHA-recognised titles (e.g. General Dentist, Specialist Orthodontist). No invented specialty names.
5. **Testimonials** — only patient-*experience* quotes by default; never clinical cure claims. Slot includes consent reminder.
6. **Before / after** — if used, require visible disclaimer: outcomes vary by individual; images represent actual treated patients with consent.
7. **MOHAP advertisement licence number** — footer + contact page include a clear editable slot: `MOHAP Adv. Licence No: [Insert]`.
8. **Facility identification** — show clinic legal/trading name, Dubai address, phone, and that care is provided in a DHA-licensed facility (placeholder).
9. **Risks / limitations** — treatment pages include a short “What to expect & limitations” note; implant/ortho pages mention assessment-dependent plans.
10. **No GA procedure promo video** — gallery guidance forbids marketing video of patients under general anaesthesia.
11. **No DHA logo** — never use DHA/government logos without written approval.
12. **Pricing** — if prices are shown, they must note variables/conditions; no bait time-limited medical inducements that cannot be met. Default template uses “written plan before treatment” instead of flash discounts.
13. **Children** — paediatric content avoids collecting/promoting identifiable child health data; consent note for under-18 imagery.
14. **Informed decision framing** — CTAs use “Book a consultation” / “Request an assessment”, not “Get the smile you deserve today”.

## UI compliance slots (must appear in Framer)

| Slot | Placement |
|------|-----------|
| MOHAP Adv. Licence No. | Footer (all pages), Contact |
| DHA-licensed facility disclaimer | Footer, About |
| Outcomes-vary disclaimer | Treatments detail, Cases/Gallery |
| Medical Director approval note | Style Guide / Instructions page for buyers |
| Patient consent note | Testimonials component, Cases CMS |

## Language to prefer vs avoid

| Prefer | Avoid |
|--------|--------|
| Evidence-based, planned care | Guaranteed results |
| May help improve comfort / function | Pain-free forever |
| Subject to clinical assessment | Same results for everyone |
| Specialist team (licence-dependent) | World’s best specialists |
| Patient experience feedback | “This cured my disease” testimonials |
| Book a consultation | Transform your life today |

## Buyer instructions (include on `/instructions`)

1. Replace all placeholder clinic details and licence numbers.
2. Have Medical Director review all public copy before publish / paid ads.
3. Obtain written patient consent before using photos or quotes.
4. Apply for / display valid MOHAP advertisement licence for promotions.
5. Do not add superiority claims, guaranteed outcomes, or GA procedure marketing videos.
6. Localise Arabic if serving Arabic-first audiences; keep medical claims consistent across languages.
